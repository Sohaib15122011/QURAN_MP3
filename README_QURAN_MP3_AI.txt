QURAN MP3 — تشغيل المساعد الحقيقي

المتطلبات: Node.js حديث واتصال بالإنترنت.

1) ضع الملفات التالية في مجلد واحد:
   quran_mp3.html
   server.js
   package.json
   .env (أنشئه بنسخ .env.example)

2) افتح ملف .env وضع مفتاح OpenAI API الخاص بك مكان النص التوضيحي.
   لا ترسل المفتاح في المحادثة ولا تضعه في HTML.

3) افتح موجّه الأوامر داخل المجلد ونفّذ:
   npm install
   npm start

4) افتح هذا العنوان في المتصفح (لا تفتح ملف HTML بالنقر المزدوج):
   http://127.0.0.1:4173/quran_mp3.html

5) لاختبار الاتصال افتح:
   http://127.0.0.1:4173/api/health
   يجب أن ترى ok=true و configured=true. إذا كانت configured=false فمفتاح API غير مضبوط أو لم يُعد تشغيل الخادم بعد حفظه.

إذا ظهر خطأ 401 فالمفتاح غير صحيح، و403/404 فالنموذج أو الصلاحية غير متاحة، و429 فتحقق من حدود الاستخدام والرصيد. بعد أي تعديل على .env أوقف الخادم ثم شغّله مجدداً.

المساعد:
- اكتب وصف التعديل ثم اضغط «تحليل ومعاينة».
- راجع التغييرات ثم اضغط «تطبيق التعديلات».
- أرفق صورة مرجعية اختيارياً، أو اضغط «إنشاء صورة تصميم» لإنتاج صورة بالذكاء الاصطناعي.

مهم جداً:
- واجهة القيادة المؤقتة في ملف HTML الحالي نموذج محلي فقط؛ لا تصلح لحماية موقع عام أو إدارة أدوار حقيقية عبر أجهزة مختلفة.
- أول حساب ينشأ في المتصفح هو القائد المحلي فقط. يجب بناء تسجيل دخول وقاعدة بيانات وصلاحيات على الخادم قبل نشر الموقع.
- لا تفتح منفذ الخادم للإنترنت ولا تنشره للعامة قبل إضافة مصادقة خادمية وتحديد صلاحيات ومعدل طلبات مناسب.
- استدعاءات OpenAI API قد تكون مدفوعة بشكل منفصل عن اشتراك ChatGPT.
